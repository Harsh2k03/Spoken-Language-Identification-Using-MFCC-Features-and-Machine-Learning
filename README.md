# Spoken-Language-Identification-Using-MFCC-Features-and-Machine-Learning
Classifies audio clips into Hindi, Gujarati, or Marathi using MFCC features. Compares an SVM/Random Forest pipeline (mean-pooled MFCCs) against a CNN (full MFCC spectrograms). Evaluated via accuracy, classification reports, and confusion matrices, with inference tested on custom recordings.
